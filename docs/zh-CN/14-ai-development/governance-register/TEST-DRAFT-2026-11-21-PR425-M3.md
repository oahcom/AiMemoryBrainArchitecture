## 2. 草案

追加到 `04-memory-compiler/reference-model/test_memory_compiler.py`：

```python
class DigestFormatTests(unittest.TestCase):
    """Negative coverage for _digest's 64-hex format check.

    M3 mutation (removing _SHA256.fullmatch) must fail at least one of these.
    """

    def _source_with_digest(self, digest):
        from memory_compiler import SourceMemory
        return SourceMemory(
            memory_id="mem:probe",
            source_event_id="event-probe",
            scope_ref="scope-probe",
            content="probe content",
            content_digest=digest,
        )

    def test_rejects_short_digest(self):
        from memory_compiler import validate_source
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest("abc123"))

    def test_rejects_correct_length_with_non_hex_characters(self):
        """64 characters, but contains 'z' and uppercase: not lowercase hex."""
        from memory_compiler import validate_source
        bad = "z" * 32 + "A" * 32
        self.assertEqual(len(bad), 64)
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest(bad))

    def test_rejects_uppercase_hex_digest(self):
        from memory_compiler import validate_source, sha256_text
        upper = sha256_text("probe content").upper()
        self.assertEqual(len(upper), 64)
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest(upper))

    def test_rejects_65_char_digest(self):
        from memory_compiler import validate_source, sha256_text
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest(sha256_text("probe content") + "a"))

    def test_accepts_valid_lowercase_hex_digest(self):
        """Positive guard: the correct digest must still pass."""
        from memory_compiler import validate_source, sha256_text
        good = sha256_text("probe content")
        self.assertEqual(validate_source(self._source_with_digest(good)).content_digest, good)
```

## 3. 五个用例各自防的是什么

| 用例 | 输入 | 预期异常 | 防的问题 |
|---|---|---|---|
| `test_rejects_short_digest` | `"abc123"` | `INVALID_CONTENT_DIGEST` | 长度过短 |
| `test_rejects_correct_length_with_non_hex_characters` | `"z"*32 + "A"*32`（**长度正确 64**） | `INVALID_CONTENT_DIGEST` | **只测长度不足会漏掉这条**——长度对但字符非法 |
| `test_rejects_uppercase_hex_digest` | `sha256_text(...).upper()`（长度正确、全十六进制、仅大小写不同） | `INVALID_CONTENT_DIGEST` | 正则只允许小写 `[0-9a-f]` |
| `test_rejects_65_char_digest` | 合法摘要 + `"a"` | `INVALID_CONTENT_DIGEST` | 长度过长 |
| `test_accepts_valid_lowercase_hex_digest` | 真实 `sha256_text("probe content")` | 无（通过） | **正向保护**，防止把校验改得过严 |

Owner 特别指出的「不要只测长度错误，还应覆盖长度正确但包含非十六进制字符」对应第 2、3 条。第 3 条更严格：长度对、全十六进制、只差大小写。

## 6. 采纳说明

- 草案使用 `SourceMemory(...)` 直接构造，不依赖 `ingest()`，因此能精确控制 `content_digest` 字段——这是 `validate_source` 的入口契约。
- 字段名 `mem:probe` / `event-probe` / `scope-probe` / `"probe content"` 是任意合法值，作者可改。
- 若作者认为 `validate_source` 不是公开契约入口，可改为经 `ingest()` 再 `replace()`，但需保证非法 digest 能到达 `_digest` 而不被更早的检查拦下。
- **草案不主张 `_digest` 的实现需要改动。** 现状（严格 64 位小写十六进制）在契约上是合理的；缺的只是测试。
