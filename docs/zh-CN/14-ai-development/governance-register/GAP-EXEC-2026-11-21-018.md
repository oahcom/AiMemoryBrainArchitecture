## 3. The largest concrete gap

Not "the least code" — the **most load-bearing missing thing**.

**`crates/agent-integration` has no adapter that produces a real context request.** 370 LOC and 8 tests, against 4264 LOC of context engine and 2901 LOC of compiler behind it.

The evidence that this is the binding constraint, not just the smallest crate:

1. It is the only crate whose declared figure (90%) is roughly accurate.
2. Every e2e test that exists crosses store↔context or store↔store. **None** crosses agent→context.
3. `#504` — the only open PR touching it — is still in review, so the gap is acknowledged in flight.
4. The three downstream crates have 199 executing tests between them. They cannot be exercised from an agent because nothing produces an agent-shaped request.

**How I would know it closed:** a test named something like `e2e_agent_to_context` that constructs a real adapter (not a mock), emits a request through `agent-integration`, has `memory-context` assemble a budgeted context, has `memory-compiler` admit the resulting write, and asserts the round trip. Today that test cannot be written, because step 1 has no implementation.
