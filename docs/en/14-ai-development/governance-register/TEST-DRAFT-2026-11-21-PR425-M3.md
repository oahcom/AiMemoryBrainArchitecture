## 2. The draft

Append to `04-memory-compiler/reference-model/test_memory_compiler.py`:

```python
class DigestFormatTests(unittest.TestCase):
    """Negative coverage for _digest's 64-hex format check.

    M3 mutation (removing _SHA256.fullmatch) must fail at least one of these.
    """

    def _source_with_digest(self, digest):
        from memory_compiler import SourceMemory
        return SourceMemory(
            memory_id="mem:probe",
            source_event_id="event-probe",
            scope_ref="scope-probe",
            content="probe content",
            content_digest=digest,
        )

    def test_rejects_short_digest(self):
        from memory_compiler import validate_source
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest("abc123"))

    def test_rejects_correct_length_with_non_hex_characters(self):
        """64 characters, but contains 'z' and uppercase: not lowercase hex."""
        from memory_compiler import validate_source
        bad = "z" * 32 + "A" * 32
        self.assertEqual(len(bad), 64)
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest(bad))

    def test_rejects_uppercase_hex_digest(self):
        from memory_compiler import validate_source, sha256_text
        upper = sha256_text("probe content").upper()
        self.assertEqual(len(upper), 64)
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest(upper))

    def test_rejects_65_char_digest(self):
        from memory_compiler import validate_source, sha256_text
        with self.assertRaisesRegex(StageError, "INVALID_CONTENT_DIGEST"):
            validate_source(self._source_with_digest(sha256_text("probe content") + "a"))

    def test_accepts_valid_lowercase_hex_digest(self):
        """Positive guard: the correct digest must still pass."""
        from memory_compiler import validate_source, sha256_text
        good = sha256_text("probe content")
        self.assertEqual(validate_source(self._source_with_digest(good)).content_digest, good)
```

## 3. What each case guards against

| Case | Input | Expected error | Guards against |
|---|---|---|---|
| `test_rejects_short_digest` | `"abc123"` | `INVALID_CONTENT_DIGEST` | too short |
| `test_rejects_correct_length_with_non_hex_characters` | `"z"*32 + "A"*32` (**correct length, 64**) | `INVALID_CONTENT_DIGEST` | **testing only short input misses this** — right length, illegal characters |
| `test_rejects_uppercase_hex_digest` | `sha256_text(...).upper()` (right length, all hex, only case differs) | `INVALID_CONTENT_DIGEST` | the regex allows lowercase `[0-9a-f]` only |
| `test_rejects_65_char_digest` | valid digest + `"a"` | `INVALID_CONTENT_DIGEST` | too long |
| `test_accepts_valid_lowercase_hex_digest` | real `sha256_text("probe content")` | none (passes) | **positive guard**, so the check is not over-tightened |

The Owner's specific point — "do not test only length errors; cover correct length with non-hex characters" — is cases 2 and 3. Case 3 is stricter: right length, all hex, differing only in case.

## 6. Adoption notes

- The draft constructs `SourceMemory(...)` directly rather than through `ingest()`, so it can control `content_digest` precisely — that is `validate_source`'s entry contract.
- The values `mem:probe` / `event-probe` / `scope-probe` / `"probe content"` are arbitrary and legal; the author may change them.
- If the author considers `validate_source` not a public contract entry, the cases can go through `ingest()` plus `replace()`, but must ensure the malformed digest reaches `_digest` without being caught earlier.
- **The draft does not claim `_digest`'s implementation needs changing.** The current strict 64-char lowercase hex is reasonable as a contract; what is missing is only the test.
