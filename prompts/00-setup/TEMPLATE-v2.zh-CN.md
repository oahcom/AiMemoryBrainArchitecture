## 6. 证据与审查
**P0 — 必需最低证据**
- 已执行 Prompt ID/版本，以及不可变提示词快照的 SHA-256，并记录在 Work Item Manifest 中。不得伪造不可用的摘要。
- Base SHA、实现 Commit SHA、最终分支 Head SHA 和准确的变更文件清单。
- 变更工件的读回确认。
- 带证据链接的验收条件处置结果及归属 Issue/PR Closeout。
- 治理要求适用时，记录独立审查结论和获授权的验收记录。

**P1 — 适用的验证证据**
- 准确测试/检查命令、环境、测试 Commit SHA、预期/实际结果和证据链接。
- 无法执行或不适用的检查标记为 NOT RUN / NOT APPLICABLE 并说明原因；不得暗示 PASS。
- R2/R3、安全、数据完整性、迁移、并发、恢复及其他适用政策保留完整测试/审查证据。P1 不是豁免。

## 使用说明
- 保留七个章节标题；对于未知内容使用 NONE、NOT APPLICABLE 或 PENDING + 原因，不得编造。
- 对准确、不可变的已执行提示词快照计算 SHA-256，并存入 Work Item 证据包/Manifest。不得在被哈希字节中放入自引用摘要。
- 本提示词不替代 Work Item Manifest、必需的全局提示词、GOV-DOC-001、AI-STD-001、ADR 或 GitHub Issue/PR 载体。
- 既有 v1 提示词继续有效并保持不可变。仅为新的执行/版本进行迁移；不得原地改写已执行提示词。
